# Matrix API Challenge

Solución para el coding challenge de Interseguro: dos APIs REST que procesan matrices mediante factorización QR y cálculo de estadísticas.

## Stack

| Servicio | Tecnología |
|----------|------------|
| API principal | Go + Fiber |
| API de estadísticas | Node.js + Express |
| Contenedores | Docker + Docker Compose |
